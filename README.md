# PyBlitz Programming Batch — 29 October 2026

Five real, runnable Python projects from the PyBlitz video batch
(2 long lectures + 5 Shorts, all programming, no Blender, no character).

## Projects
- `rag_chatbot/` — Ask Your Notes Anything: a tiny RAG chatbot (no API key).
  Run: `python3 rag_chatbot.py "What is Python?"`
- `mini_projects/` — Calculator, guessing game, password generator, quiz game,
  contact book, in one file. Run: `python3 mini_projects.py --demo`
- `bg_remover/` — Background remover (Pillow + NumPy, no model download).
  Run: `python3 bg_remover.py`
- `currency_converter/` — Live currency converter (free exchange-rate API,
  labelled built-in fallback if offline). Run: `python3 converter.py 100 USD PKR`
- `qr_studio/` — QR code generator + verifier (needs `pip install qrcode pillow`).
  Run: `python qr_studio.py "https://youtube.com/@pyblitz"`

Videos: https://youtube.com/@pyblitz — full code link is in each video description.
